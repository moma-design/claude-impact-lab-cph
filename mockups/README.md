# Design mockups

Clickable mockups for the new look of The Dream Job Configurator. Static HTML, no build step.

Open `index.html` in a browser and click through:

1. `index.html` — input page: feeling scale and LinkedIn profile link
2. `conversation.html` — the five questions as a horizontal flow, skill pills, jobs drifting up
3. `results.html` — the three rings in 3D depth; scroll to fly through, click a card for details

The content is the invented example person, Ingrid Dahl. Nothing here talks to the API.
